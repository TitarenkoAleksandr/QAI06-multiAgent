## 1. Общая характеристика проекта

| Параметр | Значение (из §1) |
|---|---|
| **Название проекта** | Лендинг «Мини-маркет» (MVP) |
| **Основное направление** | E-commerce / лендинг для проверки спроса и сбора заявок: витрина → корзина → заявка (без онлайн-оплаты) |
| **Тип проекта** | **Web** (адаптивный лендинг, mobile-first) |
| **Код проекта (в документе)** | **Не указан** (DEF-19). Код не выдуман |
| Код проекта (параметры прогона) | Jira **AITST** / Qase **QAI06** — заданы пользователем, документом не являются |
| **Версия документа** | 1.0 (draft) |
| **Статус документа** | На согласование |
| **Владелец продукта** | Product Owner (роль, без ФИО) |
| **Бизнес-заказчик** | Маркетинг / E-commerce |

**Общая функциональность (по §2).** Компании нужен быстрый и недорогой MVP-лендинг для проверки спроса на товары и сбора первых заказов. Полноценный маркетплейс (как Ozon) избыточен: нет логистики, платежей и продавцов. Минимальный путь пользователя: **зашёл → авторизовался → выбрал товары → добавил в корзину → оформил заявку**.

**Направления функциональности (4):** Авторизация (+ восстановление пароля) · Каталог товаров (+ карточка) · Корзина · Оформление заявки.

**Бизнес-цели (§3):**
- **BG-1:** ≥ 100 оформленных заявок за первый месяц.
- **BG-2:** конверсия «визит → авторизация» ≥ 25 %.
- **BG-3:** конверсия «корзина → заявка» ≥ 40 %.
- **BG-4:** ≥ 80 % заявок с валидным телефоном/email.

## 2. Границы проекта (Scope) — §4

**В скоупе:** авторизация (вход + регистрация); восстановление пароля; каталог товаров (поиск/фильтр — опционально); карточка товара (базовая); корзина; оформление заявки (без онлайн-оплаты); адаптивность (mobile-first), базовое SEO.

**Вне скоупа:** онлайн-платежи/эквайринг; личный кабинет с историей заказов; мультипродавцовость, логистика, складской учёт; рекомендации, промо, лояльность; админ-панель управления товарами.

**Проверка «скоуп ↔ требования»:** в скоупе есть «восстановление пароля», «карточка товара», «базовое SEO» и «самовывоз», однако собственных требований для SEO и самовывоза **нет** (DEF-18), восстановление пароля и карточка товара покрыты частично (DEF-09, DEF-25…27, DEF-52).
