## 1. Общая характеристика проекта

| Параметр | Значение (из §1) |
|---|---|
| **Название проекта** | Лендинг «Мини-маркет» (MVP) |
| **Основное направление проекта** | E-commerce / лендинг для проверки спроса и сбора заявок: витрина → корзина → заявка (без онлайн-оплаты) |
| **Тип проекта** | **Web** (веб-приложение, адаптивный лендинг, mobile-first) |

**Общая функциональность (по §2).** Компании нужен быстрый и недорогой MVP-лендинг для проверки спроса на товары и сбора первых заказов. Полноценный маркетплейс (как Ozon) избыточен: нет логистики, платежей и продавцов. Минимальный путь пользователя: **зашёл → авторизовался → выбрал товары → добавил в корзину → оформил заявку**.

**Направления функциональности (4):** Авторизация (+ восстановление пароля) · Каталог товаров (+ карточка товара) · Корзина · Оформление заявки.

**Бизнес-цели (§3):**
- **BG-1:** ≥ 100 оформленных заявок в первый месяц.
- **BG-2:** конверсия «визит → авторизация» ≥ 25 %.
- **BG-3:** конверсия «корзина → заявка» ≥ 40 %.
- **BG-4:** ≥ 80 % заявок с валидным телефоном/email.

## 2. Границы проекта (Scope) — исходный текст (§4)

**В скоупе (In Scope):**
- Окно/страница авторизации (вход + регистрация).
- Окно/страница восстановления пароля.
- Каталог товаров (сетка карточек, поиск/фильтр — опционально).
- Карточка товара (базовая).
- Корзина (добавление, изменение количества, удаление, итог).
- Оформление заявки (без онлайн-оплаты — заявка/самовывоз/менеджер).
- Адаптивность (mobile-first), базовое SEO лендинга.

**Вне скоупа (Out of Scope) для MVP:**
- Онлайн-платежи, эквайринг.
- Личный кабинет с историей заказов (только базовая авторизация).
- Мультипродавцовость, логистика, складской учёт.
- Рекомендации, промо-акции, программы лояльности.
- Админ-панель управления товарами (на старте — фиксированный каталог/ручное обновление).

**Проверка «скоуп ↔ требования»:** в скоупе есть «восстановление пароля», «карточка товара», «базовое SEO» и «самовывоз», но собственных требований для SEO и самовывоза **нет** (DEF-18, DEF-05-частный случай), а восстановление пароля и карточка товара покрыты лишь частично (DEF-09, DEF-25…DEF-27, DEF-52).
