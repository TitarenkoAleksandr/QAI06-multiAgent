## Как открыть и листать

Открыть `multiagent-presentation-v2.html` в браузере.

| Действие | Клавиши / способ |
|---|---|
| Вперёд | `→`, `PageDown`, `Space` |
| Назад | `←`, `PageUp` |
| Первый / последний слайд | `Home` / `End` |
| Полный экран | `F` |
| Прямой переход | добавить `#N` в URL (например, `...#5`) |
| Фиксированный слайд (для скриншотов) | `?static=N` — отключает анимации и закрепляет слайд N |

Прогресс-бар и счётчик слайдов встроены в интерфейс.

## Безопасность

- В презентации **нет** токенов, API-ключей, паролей, email и телефонов.
- Указаны только имена параметров и переменных окружения (`QASE_API_TOKEN`, `CONFLUENCE_URL` и т. п.) без значений.
- MCP: `jira` — remote `https://mcp.atlassian.com/v1/mcp`; `qase` — local `npx -y @qase/mcp-server`.
- Confluence подключён **отдельным плагином** `confluence.ts` (REST API v2, read-only), а не через MCP.
