## 2. Принципы проектирования

1. **Два блока:** **A** — доработка требований по существующим задачам Jira (обновление, а не создание); **B** — новые задачи на тестовую модель.
2. Существующие задачи `AITST-1…AITST-13` **не пересоздаются** — для них в блоке A указано, что дополнить в описании.
3. Новые задачи получают ключи `AITST-14…AITST-20`; фактические ключи присвоит Jira при создании.
4. Каждая задача обязана ссылаться на `REQ-*`; нессылающихся задач нет.
5. `open_questions` заполняются только там, где данных действительно не хватает; ничего не выдумывается.
