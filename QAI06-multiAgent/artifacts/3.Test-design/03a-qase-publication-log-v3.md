**Верификация:** `GET /v1/case/QST?limit=100&offset=0` → `total = 65`, распределение по Suite 20/8/13/6/18 полностью совпадает с планом `03-test-design-v8.md`. `qql_search` для проверки не использовался (известен кэшированный total).
