## 3. Инцидент с дубликатами и его устранение

**Что произошло:** первая попытка пакетной записи через `qase_case_bulk_create` вернула ошибку валидации клиента (числовые значения enum-полей). Несмотря на ошибку ответа, сервер фактически создал 15 кейсов — ID 66–80. После повторной записи через `qase_case_upsert` были созданы ещё 15 кейсов — ID 81–95 с идентичными заголовками.

**Действие:** duplicates 81–95 удалены через `DELETE /v1/case/QAI06/{id}`; 15 удалений, 0 ошибок. Оставлена первая партия 66–80 — она создана в Suite 11 с полными шагами, предусловиями и тегами.

**Итог:** дублей нет, счётчик 53 → 68 (ровно +15).

> Рекомендация: до устранения ошибки валидации в `qase_case_bulk_create` использовать пошаговый `qase_case_upsert` с проверкой факта записи через `qase_api GET /v1/case/{code}` после каждой партии. `qql_search` может временно отдавать устаревший total — для верификации использовать REST API.
