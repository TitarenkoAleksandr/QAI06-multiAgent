## 5. Что перенесено в поля кейса

| Поле Qase | Содержимое |
|---|---|
| `title` | Из TC артефакта (для 22, 25, 54 — название сохранено, смысл уточнён примечанием) |
| `description` | Источник (файл, TC, тип, suite), трассировка REQ, open_questions, тестовые данные, примечания |
| `preconditions` | Из TC артефакта |
| `steps` | Шаги TC как action-шаги; **expected result** TC записан в последний шаг |
| `tags` | Из TC артефакта |
| `status` | `Actual` (0) |

**Ограничения переноса:**
- В артефактах не каждый шаг имеет собственный ожидаемый результат — общий `expected result` записан в последний шаг, чтобы не выдумывать промежуточные ожидания.
- Для кейсов из v5 (S-3/S-4/S-5) **номера REQ не перенесены**: v5 построен на модели 27 REQ, v6 — на модели 58 REQ. Перенос дал бы ложную трассировку. В `description` это зафиксировано; перетрассировка требует отдельного решения.
